Основні команди Git

Create a Repository

Створити локальний репозиторій у новій папці
$ git init [project name]
Клонувати наявний репозиторій
$ git clone my_url

Observe your Repository

Показати стан файлів та індексу
$ git status
Показати зміни, які ще не додано до індексу
$ git diff
Показати зміни в індексі
$ git diff --cached
Порівняти робочі файли з останнім комітом
$ git diff HEAD
Порівняти два коміти
$ git diff commit1 commit2
Показати авторів і останні зміни рядків файла
$ git blame [file]
Показати файл у вибраному коміті
$ git show [commit]:[file]
Показати історію комітів
$ git log
Показати історію та зміни файла або каталогу
$ git log -p [file/directory]
