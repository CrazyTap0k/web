Основні команди Git

Create a Repository

Створити локальний репозиторій у новій папці
$ git init [project name]
Клонувати наявний репозиторій
$ git clone my_url

Observe your Repository

Показати стан файлів та індексу
$ git status
Показати зміни, які ще не додано до індексу
$ git diff
Показати зміни в індексі
$ git diff --cached
Порівняти робочі файли з останнім комітом
$ git diff HEAD
Порівняти два коміти
$ git diff commit1 commit2
Показати авторів і останні зміни рядків файла
$ git blame [file]
Показати файл у вибраному коміті
$ git show [commit]:[file]
Показати історію комітів
$ git log
Показати історію та зміни файла або каталогу
$ git log -p [file/directory]

Working with Branches

Показати локальні гілки
$ git branch
Показати локальні й віддалені гілки з останніми комітами
$ git branch -av
Перейти на наявну гілку
$ git checkout my_branch
Створити нову гілку без переходу на неї
$ git branch new_branch
Видалити об’єднану локальну гілку
$ git branch -d my_branch
Об’єднати branch_a з branch_b
$ git checkout branch_b$ git merge branch_a
Позначити поточний коміт тегом
$ git tag my_tag

Make a change

Додати файл до індексу
$ git add [file]
Додати зміни з поточного каталогу
$ git add .
Створити коміт з індексованих змін
$ git commit -m "commit message"
Додати зміни відстежуваних файлів і створити коміт
$ git commit -am "commit message"
Прибрати файл з індексу, зберігши робочі зміни
$ git reset [file]
Відкинути зміни відстежуваних файлів та індексу до HEAD
$ git reset --hard

Synchronize

Отримати зміни віддаленого репозиторію без злиття
$ git fetch
Отримати зміни й інтегрувати їх у поточну гілку
$ git pull
Отримати зміни та перенести локальні коміти поверх них
$ git pull --rebase
Надіслати локальні коміти у віддалений репозиторій
$ git push
