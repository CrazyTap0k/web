Послідовність роботи

  1. Спільний локальний репозиторій отримав початкову гілку develop.
  2. У першій робочій копії створено гілку demo/content та додано цю HTML-сторінку.
  3. У другій копії створено гілку demo/styles та додано її оформлення.
  4. Обидві гілки надіслано в навчальний remote командою git push.
  5. Зміни отримано командою git fetch й об’єднано в demo/teamwork.
  6. Підсумок об’єднано з гілкою develop; усі гілки збережено.
